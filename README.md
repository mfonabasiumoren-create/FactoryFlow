\# FactoryFlow — FMCG Manufacturing \& Supply Chain Platform



\## Project Overview



FactoryFlow is a local-first, cloud-native portfolio project that simulates the manufacturing and supply-chain operations of a fictional, multi-category fast-moving consumer goods (FMCG) company.



Inspired by the operating model of large consumer-goods manufacturers, the platform will connect manufacturing operations with practical DevOps engineering practices.



\## Business Scope



FactoryFlow will simulate:



\- Product and category management

\- Production batch tracking

\- Raw-material and finished-goods inventory

\- Warehouse stock movements

\- Distribution and order fulfilment

\- Operational metrics and service health



\## Technical Objectives



The project will progressively implement:



\- Python REST API development

\- PostgreSQL data persistence

\- Docker and Docker Compose

\- Automated testing and database validation

\- GitHub Actions CI/CD

\- Prometheus and Grafana monitoring

\- Application security, backups and recovery

\- Optional local Kubernetes deployment



\## Development Principles



\- Local-first development without a paid cloud subscription

\- Reproducible environments and automated quality checks

\- Secure configuration and least-privilege access

\- Clear documentation and operational runbooks

\- Incremental implementation with verification at each stage



\## Project Status



\*\*Current phase:\*\* Project foundation



The application, database, testing and DevOps components will be implemented incrementally.



\## Disclaimer



FactoryFlow is an educational simulation. It is not affiliated with, endorsed by, or a representation of the proprietary systems of any real FMCG company.
